# Word-only 项目目录

此模板只用于初始化 `word-only-v1` 项目。每个项目只接收一个分页 `.docx`，并锁定 Word 页数、页序和逐页源内容；一页 Word 始终对应一页 PPT。

## 目录责任

- `00_source/`：原始 Word、副本哈希、分页结果和 Word 内嵌素材的只读副本。
- `01_page_contracts/`：逐页源文本、复杂度调度输入和锁定哈希。
- `02_style/`：一屏实时确认结果、不可变执行合同、SHA-256 和仅供审计的 UI 预览截图。
- `06_images/generated/`：逐页初始生成和页内修复图片的唯一权威目录。
- `07_editable/`：每页通过 QA 后立即产生的独立可编辑重建包。
- `08_final/`：所有页面完成后按锁定页序机械组装的最终 PPTX、机械 QA 与摘要。

## 固定流程

1. 优先识别连续的 `第N页` 标记，此时不启动分页渲染器；完全没有标记时优先使用 Word 物理分页，LibreOffice 仅作为按需后备。
2. 在本地浏览器的一屏实时预览中确认一次，并冻结紧凑样式执行合同；审计截图不参与 Image2 生图。
3. 每页初始图独立调用 `images/generations`；只有页内局部修复可调用 `images/edits`。
4. 每张图只进行一次合并 QA，同时判断当前页整体样式、主要内容、关键事实和主要逻辑；正常页不再进入第二轮视觉检查，只有明确异常才修复或深检。
5. 已通过的页面立即独立重建；其他页面可继续生成或修复。
6. 全部页面完成后仅检查页数、真实页面身份与页序、工件、逐页 QA、可编辑性、包有效性和打开/回渲染能力，再机械组装终稿；严格哈希命中时复用项目内回渲染证据，LibreOffice 缺失本身不阻塞。
